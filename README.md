# Minecraft 聊天栏悬浮窗

读 Minecraft 客户端日志，把聊天栏消息显示在透明置顶悬浮窗里。游戏里聊天栏出现什么，悬浮窗上就显示什么，不用切出游戏去看。

在此之上还有这些功能：

- **消息提示音** —— 有玩家说话就响一声，**音效可以换成你自己的**
- **文本渲染规则** —— 给指定文字染色、替换内容、屏蔽刷屏关键词
- **AI 识图** —— 自动识别截图里的队伍信息并分配颜色
- **B站弹幕** —— 独立弹幕窗，礼物 / SC / 大航海 / 进场通知
- **游戏动态模糊** —— 给游戏画面加帧混合拖影
- **击杀反馈** —— 击杀时在游戏画面上做视觉反馈
- **插件** —— 自动 GG / 玩家查询 / 区域放大这些是插件，能自己装、自己卸

> ⚠ **封禁风险先说在前面**：**游戏动态模糊** 和 **击杀反馈里的画面效果**，是靠往游戏进程里**注入 DLL** 改游戏画面实现的，
> 这类操作在服务端 / 反作弊眼里属于灰色地带，**有可能被判定成作弊并封号**。
> 本身具有封禁记录的机器、以及被人举报，都会进一步加大封禁风险，要不要用请自行斟酌。（击杀反馈的**图标**和**提示音**不碰游戏，没有这个风险。）详见第 6、7 节。

---

## 运行环境

- Windows 10 / 11
- .NET 8 桌面运行时

## 从源码编译

```bash
dotnet build MinecraftChatOverlay.csproj
dotnet run --project MinecraftChatOverlay.csproj
```

也可以在 Visual Studio 2022 里打开 `MinecraftChatOverlay.csproj` 按 F5。

## 使用方法

1. 打开程序，在「悬浮窗显示」页选 Minecraft 日志文件。常见路径：
   - 原版 / 官方启动器：`%AppData%\.minecraft\logs\latest.log`
   - 网易我的世界 / 各类启动器：按启动器实际安装目录，一般也是 `...\.minecraft\logs\latest.log`
2. 点「开始监听」，程序会自动打开悬浮窗。
3. 游戏里聊天栏出现新消息，悬浮窗会同步显示。
4. 中文乱码的话，监听过程中直接切「日志编码」即可，对后续新日志立即生效。

## 过滤示例

日志里的一行：

```
[069月2026 09:32:12.646] [Render thread/INFO] [net.minecraft.client.gui.components.ChatComponent/]: [CHAT] 床被摧毁 > [关注某主播]某玩家 摧毁了 红队 的圣床，引发灾难。
```

悬浮窗里显示：

```
床被摧毁 > [关注某主播]某玩家 摧毁了 红队 的圣床，引发灾难。
```

`Ignoring chat session ...`、网络包日志这类不是聊天栏的输出会被自动忽略。

## 1. 悬浮窗显示

### 日志与编码

- 日志文件路径，默认填的是原版客户端的 `latest.log`
- 日志编码：**Auto / UTF-8 / GBK**。部分网易 / 国服客户端把中文写成 GBK，选 Auto 一般就能自动认对

### 外观与行为

- 尺寸与布局：悬浮窗最大宽度、最大高度（超出后内部滚动）、多少字符换行
- 透明度：悬浮窗整体不透明度、背景不透明度（后者只影响底色，不影响文字）
- 位置：拖动后的位置会被记住，重启后回到你放的地方
- 交互：鼠标点击穿透、允许选中文本（选中需要先关穿透）、始终置顶
- 字体与配色：字体、字号、字重、文字颜色、背景颜色、文字阴影；
  另有「发言玩家 ID 颜色」和「玩家内容颜色」——这两个只作用于玩家说的话
- 行为选项：最多保留消息数、显示时间、合并连续重复消息（防刷屏）、新消息滑入动画、启用后端日志

### 消息提示音

开关在「行为选项」卡片里；**只有开关打开，页尾那张「消息提示音」卡片才能动**
（关着的时候整块是灰的，不是藏起来）。

卡片里两样东西：

- **最短间隔**（默认 800ms）——连着来好几条发言时，这段时间只响第一次；填 0 = 每条都响
- **提示音** —— 从列表里挑一个，点旁边的【试听】就能听当前选中的那个

**音效可以自定义**：点【浏览…】能把任何 `wav` / `mp3` / `wma` / `m4a` 加进列表，
加完会自动选中并试听一次。自己加的会在列表里标「自定义」；
不想留了就选中点【移除】（内置的 4 个不让移除，它们随程序一起发布）。

程序自己会认出「有玩家说话」，**不需要你写任何规则**。
换服务器之后如果该响却不响，看卡片底部那行数字定位：

```
已看 128 条 · 判为发言 12 条 · 响 11 次
```

| 哪一项卡住 | 说明 |
|---|---|
| 「已看」一直是 0 | 聊天根本没进到程序里（日志路径 / 编码 / 没点开始监听） |
| 「已看」在涨、「判为发言」不涨 | 这条发言的写法程序没认出来 |
| 「判为发言」在涨、「响」不涨 | 被最短间隔挡了，或者声音文件放不出来（后面会跟一句原因） |

**内置 4 个提示音**：

| 听感 | 说明 |
|---|---|
| 单音「叮」 | 最短最清脆 |
| 双音门铃 | 先高后低 |
| 柔和长音 | 不刺耳，适合长时间挂着 |
| 8bit 像素音 | 游戏味 |

## 2. 自动 GG（已迁成插件）

自动 GG 从内置页搬出来了，现在是插件 `自动 GG`（id `goldiamond.autogg`）。在「插件」页装上并启用，
点卡片进去就是它自己的设置页 —— 触发条件 / 打开聊天栏按键 / 自动发送文字 / 用剪贴板粘贴，和以前完全一样。

> 所以导航栏里已经没有「自动 GG」这一页了。没装插件的版本里，这个功能就是不存在的。

## 3. 文本渲染规则

### 彩色渲染规则

把指定文字染成指定颜色 / 字重，也支持用正则匹配、只染其中一段。

| 字段 | 说明 |
|---|---|
| 文本 | 要匹配的内容 |
| 颜色 | 染成什么颜色 |
| 匹配颜色 | 只染其中一段时用 |
| 字重 | 普通 / 半粗 / 粗体 |
| 按正则解释 | 关着就是纯文本 |
| 高亮第几组 | 用正则时，指定染哪一段 |

### 文本替换规则

| 字段 | 说明 |
|---|---|
| 查找 / 替换为 | 要换成什么 |
| 只替换玩家发言内容 | 只动玩家说的话，不动系统公告 |
| 按正则解释 | 关着就是纯文本 |

### 屏蔽关键词

只要聊天内容里出现这个词，就**不显示到悬浮窗**（后端日志里仍然会记录）。

### AI 自动识别（截图 → 自动分配）

一有新截图就发给视觉模型识别，自动给你分配队伍色。

| 设置 | 说明 |
|---|---|
| 启用自动识别 | 总开关 |
| 接口类型 | 对话模型 / 智谱 GLM-OCR，二选一 |
| 接口地址 | OpenAI 兼容地址，例如 `https://api.openai.com/v1` |
| 模型 ID | 必须支持读图 |
| API KEY | 只存在本机，**明文**保存 |
| 截图目录 | 留空就自动按日志位置推（`.minecraft\screenshots`） |
| 提示词 | 想让它识别什么就写什么，有默认值 |
| 识别前先用 TAB 收集玩家 ID | 默认开。会短暂打开聊天栏收集 ID，之后自动关掉，**全程不按回车** |
| 按键间隔 | 默认 35ms。越小越快，太小游戏会漏键 |
| 最多收集几轮 | 默认 20，防死循环 |
| 额外请求参数 | 用来关掉模型的思考模式，按你用的模型填 |
| 上传前压缩图片 | 默认关 = 原图直传，最清楚 |

## 5. B站弹幕

B站这块的设置和主程序的设置**分开保存**，互不影响。

### 账号与连接

- 填直播间号或短号即可连接；连接成功后弹幕出现在**独立的 B站弹幕窗**里
- 可以扫码登录，也可以直接粘贴浏览器里的完整 Cookie
  （不登录就不显示真实 UID 和完整 ID；登录后弹幕完整度也更好）

### 弹幕窗外观

- 尺寸与布局：弹幕窗宽度、弹幕区高度上限（超出后内部滚动）、弹幕多少字换行、最多保留几行
- 透明度、点击穿透
- 字体、阴影、背景色与背景不透明度

### 分区显示

弹幕 / 醒目留言（SC）/ 礼物 / 进场各自独立，**每个区都能单独设「保留多少条」和「同时显示几行」**，
更早的用滚轮翻。

| 区 | 内容 | 默认字号 |
|---|---|---|
| 顶部 | 房间标题 / 主播名 / 人数 | 11 |
| 弹幕区 | 弹幕正文和用户名 | 16 |
| SC 区 | 醒目留言 | 12 |
| 礼物区 | 礼物 + 大航海 | 12 |
| 进场区 | 进场 / 关注 / 分享 | 11 |

### 顶部人数口径

顶部那个数字可以选 6 种，拿不到对应数据时会自动退回来显示人气：

| 显示 | 是什么 |
|---|---|
| 人气值 | B站官方口径，加权指标，会明显偏大 |
| 看过人数 | 本场累计来过的观众，不是当前在线 |
| 互动人数 | 本场投喂 / 发弹幕的人数 |
| 看过 + 人气 | 两个一起显示 |
| **在线人数** | 真实并发人数（默认） |
| 在线人数 + 人气 | 两个一起显示 |

### 通知开关

进场通知（**默认关**，人多时会刷屏）、礼物通知、SC 通知、大航海通知（后三个默认开）。

弹幕要不要用 B站自带的彩色弹幕颜色，也可以单独控制，只影响弹幕区。

### 礼物颜色按价格分档

礼物颜色按价格从高到低分档，一眼看出贵重程度。内置覆盖：

| 档位 | 颜色 |
|---|---|
| 大航海（舰长 / 提督 / 总督） | 红 / 橙 / 金 |
| 2 万电池以上 | 金色 |
| 1 万电池档 | 橙色 |
| 5000 电池档 | 橙红 |
| 2000 电池档 | 玫红 |
| 1000 电池档 | 紫色 |
| 300~999 电池 | 蓝色 |
| 50~299 电池 | 绿色 |
| 50 电池以下 | 淡蓝 |

列表里可以自己加 / 改 / 删；内置那份只在你没动过的情况下补全一次，删掉的不会每次启动又被加回来。

## 6. 游戏动态模糊（帧混合）

给游戏画面加上「帧混合」拖影：画面动起来的时候带上前几帧的残影。
静止画面完全不受影响；关掉之后游戏立刻回到原生的样子。

**当前支持 Minecraft Java 版**，以及其它用 OpenGL 出帧的程序。

> ⚠ **封禁风险**：动态模糊是往游戏进程里注入 DLL、直接改画面帧实现的，这在服务端 / 反作弊眼里属于灰色地带 —— 有可能被判定成作弊并封号。本身具有封禁记录的机器、以及被人举报，都会进一步加大封禁风险，用之前请自行斟酌。

### 怎么用

1. **选择游戏进程** —— 列表里是所有带可见窗口的程序，**很容易选错，选之前看清楚窗口标题**
2. 点【注入并接管】—— 成功后状态栏会显示已接管、识别到的画面尺寸和帧率
3. 勾上「开启帧混合」，再用「强度」调拖影长短（数值越大拖影越长）
4. 想让它每次自动接上，勾「下次启动自动注入这个游戏」（**默认关**，避免选错进程时被误注入）

【卸载钩子】让游戏立刻回到原生画面；钩子掉线时用【重装钩子】，不必重启游戏。

### 显示接管成功，但一直「做了帧混合 0 次」？

状态栏会直接写出原因，照着看就行：

| 状态栏里出现 | 原因 | 怎么办 |
|---|---|---|
| 帧混合=关 | 只是混合开关没开 | 把上面的「开启帧混合」打上 |
| 「在出帧但一次都没混合」 | 钩子挂上了但没干活 | 看游戏目录里的钩子日志 |
| 「目标进程在跑，但里面没有钩子 DLL」 | 没注入过，或者游戏重启过 | 重新点【注入并接管】 |
| 「钩子不在，但 DLL 还在游戏进程里」 | 之前卸载过钩子 | 它会自动重装，等一两秒；不行就点【重装钩子】 |
| 「已卸载钩子，游戏回到原生画面」 | 你点了【卸载钩子】 | 点【注入并接管】或【重装钩子】 |
| 「注入完成了，但钩子没挂上」 | 目标进程拒绝了加载（位数不对 / 被杀软拦） | 看弹窗里的提示 |

## 7. 击杀反馈

检测到**你自己的击杀**时，在游戏画面上做一次视觉反馈。
当前支持 Minecraft Java 版。

> ⚠ **封禁风险只来自「画面效果」**：上面那 8 个画面效果是靠注入 DLL 改游戏画面实现的（走的是动态模糊那条注入通路），在服务端 / 反作弊眼里属于灰色地带 —— 有可能被判定成作弊并封号。本身具有封禁记录的机器、以及被人举报，都会进一步加大这一边的封禁风险，用之前请自行斟酌。

> **击杀图标 和 击杀提示音 没有这个风险**：这两样都在本机自己弹、自己播，不碰游戏进程。怕的话可以只留它们，把画面效果全关掉。

### 效果：可多选 + 各自调大小

8 种效果可以现场对比 —— 缩放脉冲 / 边缘脉冲（颜色可自定义）/ 暗角脉冲 / 色差分离 / 抖动 /
全屏闪光 / 中心冲击环 / 故障撕裂。

- 每种可以**单独启用**，大小用百分比输入（**0~500%**，500% = 5 倍基准）
- 多个同时勾选会**叠加一起播**
- 「持续时间」所有效果共用（默认 380ms）
- 预览用你**最近一张游戏截图**实时演算，不用进游戏就能挑
- 不播放的时候，改参数会直接显示效果最强的那一帧，方便对比强弱

预览里看到的效果和进游戏之后基本一致，不会「预览好看、进游戏不一样」。

### 击杀横幅与击杀提示音

- **击杀横幅**：在画面上方显示一条文字，文字内容可以自己写，默认「击杀！」，停留时间默认 1400ms
- **击杀提示音**：击杀时播放你选中的声音。和「消息提示音」一样 ——
  可以从内置的里挑一个，也可以点【浏览…】把**你自己的音频文件**加进来（`wav` / `mp3` / `wma` / `m4a`），
  能试听、能移除

两者和画面效果**互相独立**，可以只留声音、关掉所有视觉效果。

### 连杀合并

「连杀合并窗口」默认 1.5 秒：这段时间里连着击杀会**合并成一次反馈、强度递增**，
而不是响好几次 —— 团战里不合并的话屏幕会一直在闪，反而看不清敌人。

### 前提：必须至少填一条匹配规则

规则空着的时候，这个模块**一条击杀都认不出来** —— 画面效果和提示音全是空转。
所以「匹配规则」上面有一条常驻提示，形状跟着状态走：

| 状态 | 显示 |
|---|---|
| 一条规则都还没填 | 琥珀色的「必须填了匹配规则才会生效」 |
| 已经填了 | 薄荷色的「已经填了 N 条匹配规则」 |

两边都有【查看填写教程】按钮，点开是一个独立弹窗，讲的是：

1. 为什么非填不可（软件不知道哪个玩家是你，只会拿规则去比对聊天内容）
2. 一条规则长什么样：「你的 ID」+「紧挨着的一小段固定词」
3. 怎么用【生成并加一行】让软件自己切规则（示例消息 + 敌方名字 → 一条规则）
4. 一局里有几种写法就写几条
5. 填完怎么自检（【试一条】+ 卡片底部那行数字）
6. 两个最容易踩的坑：ID 填裸名字、什么时候才要勾「剥离方括号前缀」

### 匹配规则：写「你的 ID + 一小段固定词」，可以写多条

程序从聊天内容里认你的击杀。不同服务器的写法不一样，甚至一局里就好几种
（近战 / 远程 / 爆炸各一套），所以规则做成**一行一条、命中任意一条就算**：

```
你的ID 击败了
你的ID >> 拿下
```

规则默认按**纯文本**处理（`.` `[` `(` 都只是普通符号，不用转义）；想写模式再勾「按正则解释」。
空行和 `#` 开头的行会被跳过，方便写注释。

**三个刻意的设计**：

1. **不要求出现在行首** —— 你的 ID 一会儿在前（`你 击败了 某人`），一会儿在后（`某人 被 你 击败了`），
   要求行首会让其中一种永远匹配不到
2. **不含敌方名字、不含收尾** —— 收尾是 `!` 还是 `，达成连杀！` 都不影响
3. **可以写多条** —— 一局里有几种写法就写几条

### 规则不用自己写

填三样，点【生成并加一行】：

| 填什么 | 例子 |
|---|---|
| 你自己的 ID | `你的ID` |
| 一条击杀消息（从日志或悬浮窗复制） | `某玩家 被 你的ID 击败了` |
| 这条消息里敌方名字那一截（只当切点，不写进规则） | `某玩家` |

程序按敌方名字的位置切：你的 ID 在它**后面**，就取它**之后**那段；
在它**前面**，就取它**之前**那段。生成的规则会显示出来、可以直接改；已有的规则不会重复加。

> **一个可能省你事的事实**：单条规则 `你的ID 击败了` 其实**同时覆盖两种顺序** ——
> 因为 `某玩家 被 你的ID 击败了` 里也含 `你的ID 击败了`。
> 所以写多条真正要解决的是**不同动词 / 不同写法**（`击败了` / `射杀了` / `>> 拿下`），不是顺序问题。

### VIP 标识和称号会被自动剥掉

击杀消息里可能带 `[vip1]`、`[25阶1003⚝]`、`【称号】` 这类装饰，写死名字的规则会失效。
「剥离方括号前缀」默认开着，匹配前会把这几类装饰一起去掉：

| 形态 | 例子 |
|---|---|
| 半角方括号块 | `[vip1]` `[25阶1003⚝]` |
| 全角方括号块 | `【称号】` |
| VIP 图标 | 游戏里那种小图标，会显示成 `[vipN]` |

剥完敌方名字可能被削掉一段 —— 无所谓，它只用来显示，不参与判断。

### 卡片底部那行数字是自检用的

```
规则 3 条 · 已看 128 条 · 匹配 5 条 · 最后一次 19:20:31 命中「你的ID 击败了」
```

**匹配**和**画面**是两个独立的故障点，先看匹配有没有认出来：

| 现象 | 说明 |
|---|---|
| 「已看」一直是 0 | 聊天没进到程序里（日志路径 / 编码 / 没点开始监听） |
| 「已看」涨、「匹配」不涨 | 规则不对 → 用【试一条】粘条真实消息进去看 |
| 「匹配」涨、画面不动 | 确认是当前这版程序；当前支持 OpenGL（Java 版） |

## 9. 插件

「插件」页是插件的地盘：市场、导入、启用 / 禁用、进插件自己的页、卸载。

| 操作 | 在哪 |
|---|---|
| 浏览并安装 | 右上角【插件市场】（清单就是你自己的 GitHub 仓库 `market/`） |
| 装本地 zip | 右上角【添加插件】，也可以直接把 zip 拖到这一页 |
| 启用 / 禁用 | 卡片右上角的开关 |
| 进插件自己的页 | 点卡片本身（点开关、点【卸载】都只做各自的事） |
| 打开插件目录 | 右键卡片 →「打开这个插件的目录」 |
| **卸载** | 卡片右侧的【卸载】按钮；进了插件页之后，页头也有一个【卸载这个插件】 |

**卸载会把这个插件连同它自己的数据目录一起删掉** —— `plugins\<id>\` 和 `plugin-data\<id>\`
两个目录都没了，删之前会弹确认框。

> 插件跑在本程序里，权限和本程序一样。只装你信任来源的插件包。

随仓库提供的插件：**自动 GG**、**玩家查询**、**区域放大**、**网易云歌词** 等。
想自己写一个，见下面「插件开发」。
